# Unreleased feature notes

One file per change, so two open pull requests never edit the same lines.

- Add a new file here with your change: `<issue>-<short-name>.md`, for example
  `2410-empty-state.md`.
- Start it with a `### Title (#issue)` heading, then the bullets, as an entry in
  `docs/feature_notes.md` is written.
- Don't add to the "Unreleased" section of `docs/feature_notes.md` in a pull request.

At a release the files here are moved into `docs/feature_notes.md` under the new
version heading, and deleted.
